Understand what keeps viewers watching.

Capvolve Analytics collects performance reports for the Capvolve YouTube channel so its owner can review videos and improve future episodes.

Private tool · read-only Google access

What the tool reads

Channel identity and aggregate video reports, including views, watch time, audience retention, engagement and subscriber changes, where YouTube makes them available.

How it operates

The channel owner authorizes access through Google. A scheduled collector runs on the owner’s Windows computer and saves reports for the owner’s analysis.

Access is for the channel owner

This is a private operational tool, not a public sign-up service. It uses YouTube Analytics API and YouTube Data API with read-only permissions. YouTube Reporting API is enabled for possible future bulk reports; bulk collection is not yet connected.

The public website describes the application and its data practices. The analytics collector runs separately on the owner’s computer.
